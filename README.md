# ملفات موقع نَوْم للنشر المحلي

تم بناء الموقع كواجهة ثابتة تعمل بالكامل داخل المتصفح، لذلك لا يحتاج إلى قاعدة بيانات أو خادم Backend.

## النشر على Apache أو Nginx

ارفع **محتويات مجلد `dist`** إلى مجلد الموقع العام في الاستضافة، مثل:

- Apache: `/var/www/html/`
- Nginx: `/usr/share/nginx/html/`

تأكد من رفع ملف `index.html` ومجلد `assets` وملف `manus-routes.json` كما هي.

## التشغيل محليًا بدون Apache أو Nginx

من داخل مجلد `dist` شغّل:

```bash
python3 -m http.server 8080
```

ثم افتح:

```text
http://localhost:8080
```

لا تفتح `index.html` مباشرة عبر `file://` لأن المتصفح قد يمنع تحميل ملفات JavaScript الحديثة من نظام الملفات.

## ملاحظات

- الحسابات تعمل فورياً داخل المتصفح.
- لا توجد حاجة إلى تسجيل دخول أو متغيرات بيئة.
- الموقع يدعم الهاتف والكمبيوتر واتجاه RTL.
- الاسم الظاهر في التذييل: تصميم: حسين محمد بالحاج.
